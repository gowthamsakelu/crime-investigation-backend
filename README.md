# Crime Investigation Backend

## Overview

A REST API built using FastAPI and SQLite for managing criminal investigation records.

## Features

- Create Cases
- Update Cases
- Delete Cases
- Search Cases
- Manage Suspects
- Manage Witnesses
- Manage Evidence
- SQL JOIN Queries
- Foreign Keys
- ON DELETE CASCADE

## Tech Stack

- Python
- FastAPI
- SQLite
- Pydantic

## Project Structure

```
main.py
database.py
crime.db
```

## Installation

```bash
pip install -r requirements.txt
```

Run the server:

```bash
uvicorn main:app --reload
```
